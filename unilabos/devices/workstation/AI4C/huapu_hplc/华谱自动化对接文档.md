# 华谱自动化对接文档

## 文档概述

实现华谱科仪软件的自动化处理：采集、处理、报告。

## 接入流程

- 接入配置
- 开发规范
- 通讯协议：HTTP

## 通用请求

### Headers

| 字段 | Value | 说明 |
| --- | --- | --- |
| Content-Type | `application/json;charset=UTF-8` | JSON 传输 |

## 通用返回

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 状态码 |
| msg | string | 错误信息 |
| data | object | 响应数据 |

### 状态码说明

| code | 说明 |
| --- | --- |
| 0 | 成功 |
| 1 | 失败 |

### 响应示例

```json
{
  "code": 0,
  "msg": "成功",
  "data": null
}
```

### 11. 获取样品盘传感器状态

说明：通过调用该接口，可以获取在更换样品盘的过程中样品盘的状态（是否放置妥当）。

- 地址：`/project/findTraySensor`
- 请求方式：`POST`

#### 请求参数

| 字段 | 类型 | 必选项 | 说明 |
| --- | --- | --- | --- |
| instrumentId | long | YES | 仪器系统 ID |
| trayNum | int | YES | 盘号（1、2） |

#### 请求示例

```json
{
  "instrumentId": 1,
  "trayNum": 1
}
```

#### 响应参数

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| traySensor | int | 样品盘传感器状态 |

#### traySensor 说明

| 值 | 说明 |
| --- | --- |
| 0 | 放置妥当（2 个传感器都触碰） |
| 1 | 未放置妥当（只有 1 个传感器触碰） |
| 2 | 无样品盘（2 个传感器都未触碰） |

只有 `0` 代表放置成功。

## 设备状态参数说明

### 泵单元（Pump）

类型：Array

| 参数 | 格式/说明 | 字段 |
| --- | --- | --- |
| Ready/Busy 信息 | 0：Ready；1：Busy | pStatus |
| Busy 状态 | 0x00：设备空闲（Ready）；0x01：初始化；0x03：泵关闭；0x04：灌注；0x06：错误状态；0x08：自动调零；0x09：时间程序运行；0x0B：等待重启；0x0C：命令执行中 | pBusy_Code |
| Error 状态 | 0：无错误 | pError_Code |
| 数据收集状态 | 0：停止中；1：收集中；2：等待 Start 同步状态 | pGather_Status |
| 泵 ON/OFF 状态 | 0：OFF；1：ON | pOn_Status |
| 当前压力 | 浮点，单位：bar | pPress |
| 设定流量 | 浮点，单位：mL/min | pFlowSet |
| 当前流量 | 浮点，单位：mL/min | pFlow |
| 当前比例（A 百分比） | 浮点，单位：% | pConcA |
| 当前比例（B 百分比） | 浮点，单位：% | pConcB |
| 当前比例（C 百分比） | 浮点，单位：% | pConcC |
| 当前比例（D 百分比） | 浮点，单位：% | pConcD |

### 进样器单元（Sampler）

| 参数 | 格式/说明 | 字段 |
| --- | --- | --- |
| Ready/Busy 信息 | 0：Ready；1：Busy | pStatus |
| Busy 状态 | 0x00：设备空闲（Ready）；0x01：初始化；0x03：泵关闭；0x04：灌注；0x06：错误状态；0x08：自动调零；0x09：时间程序运行；0x0B：等待重启；0x0C：命令执行中 | pBusy_Code |
| Error 状态 | 0：无错误 | pError_Code |

| 参数 | 格式/说明 | 字段 |
